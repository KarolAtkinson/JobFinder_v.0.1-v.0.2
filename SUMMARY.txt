PROJECT OVERVIEW
================

This repository contains TWO VERSIONS of an intelligent job application system:

1. JSRE_01 - CV Optimiser (Local Desktop App)
   - Standalone, offline-first application
   - Local CV tailoring with optional Ollama AI
   - Private, no cloud dependencies
   - Easy setup (5 minutes)

2. JF_os_01 - ApplyAgent (Full-Stack Web Application)
   - FastAPI backend + React frontend
   - Automated job discovery and submission
   - Multi-provider LLM integration
   - Complex architecture (learning project)
